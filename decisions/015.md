## 015: Quote slug renames are detected by a content-keyed manifest (2026-08-19)

**Decision:** `scripts/extract-non-diary-quotes.py` keeps `data/quote-slug-map.json`, a map from a content key (work slug + whitespace-normalized quote text, sha256 prefix) to the slug it last produced. On every run it compares the manifest with the slugs it just generated; each key whose slug moved gets a `/quotes/OLD/ -> /quotes/NEW/ 301` appended to a managed block at the end of `static/_redirects` (sources already ruled anywhere in the file are skipped). Keys no longer produced are dropped: a deleted quote should 404. The check is skipped, like stale cleanup, when dataless source files were skipped, so a partial scan can never rewrite the manifest.

### Why

A non-diary quote's slug is `{work}-q-{hash}` where the hash is of the heading `:ID:`, or of the quote text when the heading has none. A heading that gets an ID after its first export therefore moves to a new slug with nothing to say so. bibliographic-notes `45e22f08` (2026-08-02) added IDs to 35 files and moved 23 quotes; the only signal was a Search Console "Not found (404)" alert seventeen days later. Works have `data/id-slug-map.json` for the same purpose; quotes had nothing.

The key is the quote text rather than the ID precisely because the ID is the thing that changes in the failure we want to catch. Replaying the extractor on the pre-`45e22f08` files against the seeded manifest reports exactly the 23 renames that were redirected by hand in `f5f401b`.

**Rejected:**
- **Refuse to export when a previously generated `-q-` slug disappears without a rule.** Blocks every quote export, including unrelated ones, until someone hand-writes redirects the script already has enough information to write itself.
- **Key the manifest by heading ID.** Cannot match a quote across the no-ID -> ID transition, which is the only rename source seen so far.
- **Generate `_redirects` from a Hugo template or a separate data file.** Netlify reads only `static/_redirects` and `netlify.toml`; the file already mixes hand and bulk-generated rules, and a delimited managed block is the smallest change that keeps both editable.
- **Make slugs never depend on IDs.** Would rename all 714 current `-q-` slugs at once and break every URL Google already has.

**Limits:** editing a quote's text while its heading still has no ID changes both the key and the slug, so that rename is not detected. The ID pass now runs on save, so the window is small. A text edit on a heading with an ID changes the key but not the slug, which reads as delete + add with no redirect needed.

**Files:** `scripts/extract-non-diary-quotes.py`, `data/quote-slug-map.json`, `tests/test_extract_non_diary_quotes.py`, `static/_redirects` (managed block).
