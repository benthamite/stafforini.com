# 018: Scaled equity proxy is a third mode; equity proxy stays as its 100% endpoint (2026-08-22)

**Decision:** Both 13F notes gained an `option_equity_fraction` parameter in
`compute_return`/`daily_cumulative` (`equity_only` mode): option rows are held
as a fixed fraction of reported notional in plain shares, fully invested at the
scaled weights. Headline fraction 30% (the delta rule of thumb copycats use in
practice), with a printed 15/30/50/100% sweep. The full-notional equity proxy is
kept, reframed as the fraction = 1.0 endpoint.

**Rejected:**
- **Replace the equity proxy with the scaled proxy:** it is the delta = 1 bound
  of the same one-parameter family, both published posts' histories and the
  SALP comparison were built on it, and the [option | scaled | full-notional]
  bracket is more informative than any single linear line.
- **Static per-position delta at the rebalance date:** false precision — the
  filing does not disclose the contract, so any per-asset delta comes from our
  own representative-contract rule, which *targets* |delta| ≈ 0.15; the result
  is a flat ~15–20% rule dressed up as measurement (achieved mean |delta| 0.21).
- **Dynamic daily delta replication:** the principled delta-equivalent given
  the contract assumption, but untradeable for the copycat audience (daily
  rebalancing); deferred as a possible future analysis-only line.

**Files:** both notes' lib/perf/chart blocks; excursus prose now states the
equity proxy deliberately makes no delta adjustment.
