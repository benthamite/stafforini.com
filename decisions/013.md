## 013: Recompute SA LP sensitivity after disclosures or model changes (2026-08-15)

**Decision:** Run the Situational Awareness LP sensitivity sweep after each new filing and after any model change. Do not run it during routine daily data refreshes. A filing refresh is incomplete if the required sweep fails or leaves `err` cells.

**Rejected:**
- **Run sensitivity daily.** The historical option sweep consumes many MarketData credits while unchanged filings and assumptions produce the same result.
- **Run sensitivity only when requested manually.** This can leave the published robustness claims out of sync with a new portfolio or changed model.
- **Publish the other artifacts when sensitivity fails.** This creates mixed-generation output that appears current even though a core analysis is stale.

**Files:** `scripts/sa-lp-refresh.sh`, `scripts/sa-lp-filing-check.py`, `.codex/skills/update-situational-awareness-filing/SKILL.md`.
