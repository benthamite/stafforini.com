## 012: The triage skill keeps its scope gate; autonomy would need a CLAUDE.md amendment (2026-08-08)

**Decision:** `gsc-indexing-triage` keeps its scope gate — deploy, Search Console validation, and Gmail archiving each require explicit authorization in the invoking request. The "run to completion" rewrite drafted on 2026-08-08 was declined. Its non-authorization half was applied instead: finish the work in one turn, never hand back a to-do list of work you could have done yourself, never let one blocked item strand the unblocked ones, and say when a blocked decision gates a later step.

### Why the rewrite could not work as drafted

All three gated actions are externally visible. Global `~/.claude/CLAUDE.md` forbids externally visible actions without explicit confirmation, and skills rank *below* user instructions in precedence. A skill asserting authority that CLAUDE.md withholds does not acquire it — it just creates a contradiction that resolves against the skill, leaving the gate binding at runtime while the file claims otherwise.

The earlier session recorded this as "the edit was refused by the permission classifier," framing it as a guardrail obstacle to retry later. That framing is wrong and would have wasted another attempt. Supporting evidence that the classifier's objection is narrow and correct: an unrelated edit to the same `SKILL.md` was permitted this session, so what it blocks is self-authorization specifically, not the file.

Diagnosis of the original complaint: the failure that prompted the patch was timidity *inside* an authorized scope, not the scope itself. That is what the applied half addresses.

**Rejected:**
- **Apply the patch in full.** Produces a skill whose text is overridden by CLAUDE.md at runtime. Worse than the status quo, because a future agent reads a false statement of its own authority and has to reconcile two conflicting instructions.
- **Apply it in full and amend global CLAUDE.md to carve out this skill.** The only route that would actually work, and still available if Pablo wants it. Declined for now: this same session is a live argument for a human checkpoint before publishing, since an unattended run would have deployed the 8,891-page deletion from decision 011.
- **Drop the patch entirely.** Discards the genuinely useful half, which addresses a real and recurring failure.
