# 019: Publish standalone copycat scripts as generated artifacts (2026-08-27)

**Decision:** Keep the Org/Babel notes canonical and deterministically generate self-contained public Python CLIs into `static/code/` during the relevant refresh. The VARA script embeds SALP's current model so it remains standalone while preserving decision 016; unexpected source shapes and local paths fail loudly.

**Rejected:**
- **A gist or separate repository:** adds another synchronization surface between the published analysis, its source, and the downloadable code.
- **Manually maintain the Python files:** they would drift from the Babel blocks that produce the published results.
- **Naive tangling or concatenation:** Babel-only top-level returns, injected state, repeated noweb libraries, local paths, and VARA's SALP Org dependency do not form runnable standalone programs without explicit transformation.

**Files:** `scripts/generate-copycat-scripts.py`, `static/code/*.py`, both refresh scripts.
